# homebrew-snapshot

Homebrew tap for [EasySnaps](https://easysnaps.org) — a screen capture and screenshot editor for macOS.

## Install

```sh
brew tap easysnaps/snapshot
brew install --cask easysnaps
```

## Update

```sh
brew upgrade --cask easysnaps
```

(EasySnaps also ships with built-in Sparkle updates, so new versions install automatically while the app is running.)

## Uninstall

```sh
brew uninstall --cask easysnaps
```
